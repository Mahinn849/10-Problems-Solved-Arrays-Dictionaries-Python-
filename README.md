# 10 Problems Solved with Arrays and Dictionaries in Python

This repository contains solutions to 10 different problems using arrays and dictionaries in Python. Each problem is solved with clear and concise code, demonstrating various programming concepts and techniques.

## Problems Covered

1. **Find Largest and Minimum Number in Array**  
   This program finds the largest and smallest numbers in a given array.

2. **Count Even and Odd Numbers**  
   This program counts the total number of even and odd numbers in an array.

3. **Search for an Element**  
   This program allows the user to search for a specific name in a list of names.

4. **Remove Duplicate Values**  
   This program removes duplicate values from an array and returns a unique list.

5. **Student Marks Analysis**  
   This program analyzes student marks, finding the highest, lowest, and average marks.

6. **Student Record Using Dictionary**  
   This program retrieves student marks from a dictionary based on the student's name.

7. **Count Word Frequency**  
   This program counts the frequency of words in a list.

8. **Product Price Lookup**  
   This program allows the user to look up the price of a product from a dictionary.

9. **Grade Counter**  
   This program counts the occurrence of each grade in a list of grades.

10. **Inventory Management**  
    This program manages inventory by allowing users to purchase items and updates the stock accordingly.

## Usage

To run any of the programs, simply execute the `10problemsnew.py` file in a Python environment. Make sure to have Python installed on your machine.
