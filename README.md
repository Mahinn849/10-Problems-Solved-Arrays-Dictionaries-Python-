# 10 Problems Solved with Arrays and Dictionaries in Python

This repository contains solutions to 10 different problems using arrays and dictionaries in Python. Each problem is implemented in the `10problemsnew.py` file.

## Problems Covered

1. **Find Largest and Minimum Number in Array**  
   This function finds the largest and smallest numbers in a given array of integers.

2. **Count Even and Odd Numbers**  
   This function counts the total number of even and odd numbers in a list.

3. **Search for an Element**  
   This function allows the user to search for a specific name in a predefined list of names.

4. **Remove Duplicate Values**  
   This function removes duplicate values from a list and returns a unique list.

5. **Student Marks Analysis**  
   This function analyzes student marks, finding the highest, lowest, and average marks, as well as counting how many students scored 50 or above.

6. **Student Record Using Dictionary**  
   This function retrieves a student's marks based on their name from a dictionary of student records.

7. **Count Word Frequency**  
   This function counts the frequency of words in a list and returns a dictionary with the word counts.

8. **Product Price Lookup**  
   This function allows the user to look up the price of a product from a predefined dictionary of products.

9. **Grade Counter**  
   This function counts the occurrences of each grade in a list and returns a dictionary with the grade counts.

10. **Inventory Management**  
    This function manages an inventory by allowing the user to purchase items and updates the inventory accordingly.

## Usage

To run the solutions, simply execute the `10problemsnew.py` file in a Python environment. Each problem is clearly defined and can be tested individually.
